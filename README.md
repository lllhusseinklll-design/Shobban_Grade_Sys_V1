# رصد كتطبيق موبايل (PWA)

## الملفات

| الملف | المكان في مشروع رصد |
|--------|---------------------|
| `index.html` | الجذر (مستبدل بالنسخة التي فيها روابط PWA) |
| `manifest.webmanifest` | الجذر |
| `sw.js` | الجذر |
| `pwa-register.js` | الجذر |
| `icons/icon-192.svg` | `icons/` |
| `icons/icon-512.svg` | `icons/` |

## الهيكل النهائي

```
مشروع-رصد/
  ├── index.html
  ├── manifest.webmanifest
  ├── sw.js
  ├── pwa-register.js
  └── icons/
        ├── icon-192.svg
        └── icon-512.svg
```

## النشر

1. انسخ كل الملفات أعلاه إلى مشروع رصد (نفس المواضع).
2. ادفع إلى GitHub / انشر على Vercel.
3. افتح الموقع من الموبايل:
   - **Android:** القائمة ⋮ → تثبيت التطبيق / إضافة إلى الشاشة الرئيسية
   - **iPhone (Safari):** مشاركة → إضافة إلى الشاشة الرئيسية

## ملاحظات

- يجب أن يكون الموقع على HTTPS (Vercel يوفّره تلقائياً).
- على iPhone استخدم Safari فقط للتثبيت.
- بعد التثبيت تظهر أيقونة «رصد» وتفتح بملء الشاشة.
- غيّر الأيقونات في `icons/` لاحقاً إن أردت تصميماً مختلفاً (يفضّل PNG أيضاً لبعض الأجهزة القديمة).


## الرصد المتزامن للمعلمين (تحديث 2026-10-16)

**مهم قبل نشر نسخة الواجهة الجديدة:**

1. خذ نسخة احتياطية من قاعدة بيانات Supabase ومن ملفات النشر الحالية.
2. افتح Supabase Dashboard → SQL Editor، وشغّل الملف `supabase/migrations/20261016_atomic_grade_merge.sql`.
3. تأكد من نجاح إنشاء الدالة `public.merge_grade_system_state`.
4. انشر ملفات هذه الحزمة بعد تطبيق ترحيل قاعدة البيانات. لا تنشر الواجهة وحدها؛ الإصدار الجديد يعتمد على دالة الدمج الذري.
5. اختبر بحسابين معلمين مختلفين ومادتين/فصلين مختلفين، وأدخل درجات واحفظهما بالتزامن، ثم أعد تحميل الجهازين وتحقق من بقاء الدرجات.

تعالج الدالة دمج مصفوفة الدرجات ذرياً داخل PostgreSQL، لتجنب فقد الدرجات بسبب تزامن قراءة سجل المرحلة ثم رفعه من جهازين. إذا لم تكن دالة قاعدة البيانات موجودة أو لم تسمح الصلاحيات باستدعائها، ستظهر حالة خطأ في المزامنة؛ لن يعود التطبيق تلقائياً إلى رفع سجل المرحلة بالطريقة القديمة غير الآمنة.
